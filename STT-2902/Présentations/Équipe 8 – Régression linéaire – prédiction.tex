\section*{Équipe 8 – Régression linéaire - prédiction}

Objectif : Illustrer l'utilisation d'un modèle de régression pour faire des prédictions.


\vspace{1cm}
Suggestions :
\begin{itemize}
    \item Donnez un modèle simple (ex. : prédire le temps d’étude en fonction de la note finale).
    \item Demandez aux autres d’utiliser ce modèle pour faire des prédictions sur de nouveaux cas.
    \item Soulevez les dangers d’extrapolation.


\end{itemize}

\vspace{1cm}

\textbf{Requis:}

\begin{enumerate}
    \item Utiliser un jeu de données réel ou réaliste pour réaliser au moins deux prédictions et comparer ces prédictions aux valeurs observées.
    \item Illustrer graphiquement la zone de validité du modèle et expliquer pourquoi les prédictions hors de cette zone (extrapolation) peuvent être risquées.
\end{enumerate}
