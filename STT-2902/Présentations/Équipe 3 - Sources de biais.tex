\section*{Équipe 3 – Sources de biais}

Objectif : Illustrer les principaux types de biais (de sélection, de non-réponse, de mesure, etc.).



\vspace{1cm}
Suggestions :
\begin{itemize}
    \item Mettez en place un jeu de rôle ou une simulation d’enquête biaisée (questions orientées, sélection non aléatoire...).
    \item Faites réfléchir les autres : où sont les biais ?

\end{itemize}


\vspace{1cm}
\textbf{Requis} :
\begin{enumerate}
    \item Montrer un exemple de question de sondage formulée de manière biaisée et demander aux autres de proposer une reformulation neutre.
    \item Présenter un graphique ou tableau comparant les résultats obtenus avec et sans biais.
\end{enumerate}
