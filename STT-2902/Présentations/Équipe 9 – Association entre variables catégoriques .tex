\section*{Équipe 9 – Association entre variables catégoriques}

Objectif : Montrer comment on peut détecter une association entre deux variables qualitatives.


\vspace{1cm}
Suggestions :
\begin{itemize}
    \item Créez un jeu-questionnaire avec deux variables (ex. : préférences musicales selon le sexe ou l’âge).
    \item Présentez un tableau croisé.
    \item Faites deviner aux autres équipes si une association semble présente (avant de montrer les tests ou les pourcentages conditionnels).


\end{itemize}

\vspace{1cm}
\textbf{Requis}:

\begin{enumerate}
    \item Construire un tableau croisé des données recueillies pendant l’activité et calculer au moins un pourcentage conditionnel.
    \item À partir de ces données, expliquez clairement l'indépendance de variables catégoriques.
\end{enumerate}
